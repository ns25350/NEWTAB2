# Pixel Home New Tab

Google Pixelのホーム画面に着想を得た、時間割ウィジェット付きの新しいタブページです。追加のライブラリやビルド作業は不要です。

## 主な機能

- Google検索と検索候補
- アプリアイコン風ショートカットの追加・編集・削除
- アイコンとウィジェットのドラッグ並べ替え（マウス・タッチ対応）
- デジタル／アナログ時計
- Firebaseから取得する今日・明日の時間割
- クラスと「明日の時間割へ切り替える時刻」の設定
- 5種類のMaterial You風カラーテーマ
- レスポンシブ表示、ダークテーマ、設定の自動保存

## ファイル

- `manifest.json`：Chrome拡張機能の設定
- `index.html`：画面構造
- `style.css`：デザインとレスポンシブ表示
- `app.js`：検索、時計、時間割、ショートカット、配置保存

4ファイルをすべてリポジトリの一番上の階層に置いてください。

## Chromeへの読み込み方

1. Chromeで `chrome://extensions/` を開きます。
2. 右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. この4ファイルが入ったフォルダを選択します。
5. 新しいタブを開きます。

## 時間割

時間割は次のFirebase Realtime Databaseから取得します。

`https://johou7-275be-default-rtdb.firebaseio.com/timetable.json`

元のNewTabにあるクラス一覧、今日／明日の切り替え、指定時刻以降に明日を先に表示する動作を引き継いでいます。取得に成功したデータはブラウザ内にもキャッシュされ、通信に失敗した場合は直近のデータを表示します。

## 補足

- 設定とショートカットは、そのChromeプロファイルの `localStorage` に保存されます。
- 検索候補を取得できない場合でも、通常のGoogle検索は使用できます。
- ショートカットのfaviconを取得できない場合は、サイト名の先頭文字を表示します。
