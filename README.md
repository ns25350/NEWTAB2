# Home Grid New Tab

iOSのホーム画面のような質感と操作感を目指した、Chrome用の新しいタブページです。検索、時計、時間割、ショートカットを同じグリッド上に自由に配置できます。追加ライブラリやビルド作業は不要です。

## 主な機能

- 検索窓・時計・時間割・ショートカットをグリッド単位で移動／拡大縮小
- 列数、1行の高さ、間隔を設定できる可変グリッド
- ウィジェットの大きさに応じて時計と時間割の内側レイアウトを自動調整
- Google検索と検索候補
- ショートカットの追加・編集・削除
- デジタル／アナログ時計、12時間／24時間表示
- Firebaseから取得する今日・明日の時間割
- クラスと「明日の時間割へ切り替える時刻」の設定
- 背景画像のアップロードと端末内保存
- 背景画像からアクセント色と明暗を自動作成、または手動テーマを選択
- 透過ガラス、ぼかし、柔らかいシャドウを使ったiOS風デザイン
- 設定画面とショートカット編集画面は、画面外を押して閉じられる仕様
- マウス、タッチ、ペン操作に対応

## ファイル

- `manifest.json`：Chrome拡張機能の設定
- `index.html`：画面構造
- `style.css`：iOS風デザイン、可変グリッド、サイズ適応
- `app.js`：配置編集、検索、時計、時間割、背景、テーマ、保存処理

この4ファイルと `README.md` を、リポジトリの一番上の階層に置いてください。

## Chromeへの読み込み方

1. ZIPを展開します。
2. Chromeで `chrome://extensions/` を開きます。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. `manifest.json` が入った `NEWTAB2-package` フォルダを選択します。
6. 新しいタブを開きます。

## 使い方

- 右上の「編集」を押すと、各アイテムを移動・拡大縮小できます。
- ウィジェット上部のつまみ、またはショートカット本体をドラッグすると移動します。
- 右下のハンドルをドラッグすると、グリッド単位で大きさを変更します。
- 右上の歯車から、グリッド密度、背景、テーマ、表示するウィジェットを設定します。
- 背景の「自動」を有効にすると、アップロード画像からアクセント色と明暗を抽出します。
- 設定画面の外側を押すと、そのままホーム画面へ戻ります。

## 時間割

時間割は次のFirebase Realtime Databaseから取得します。

`https://johou7-275be-default-rtdb.firebaseio.com/timetable.json`

元の `ns25350/NewTab` にあるクラス一覧、今日／明日の切り替え、指定時刻以降に明日を先に表示する動作を引き継いでいます。取得に成功したデータはブラウザ内にもキャッシュされ、通信に失敗した場合は直近のデータを表示します。

## 保存について

- 配置、設定、ショートカットは、そのChromeプロファイルの `localStorage` に保存されます。
- アップロードした背景画像は、そのChromeプロファイルの `IndexedDB` に保存されます。画像は外部へ送信しません。
- 検索候補を取得できない場合でも、通常のGoogle検索は使用できます。
- ショートカットのfaviconを取得できない場合は、サイト名の先頭文字を表示します。
