# Home Grid New Tab v0.4

Chromeの新しいタブを、iPadのホーム画面のように使えるChrome拡張機能です。検索、時計、時間割、天気、ショートカット、フォルダを自由に配置できます。ビルド作業や外部ライブラリは不要です。

## v0.4の主な変更

- 半透明・ぼかし・光沢・自然な影を使ったiOS / Liquid Glass風デザイン
- Chromebookのタッチ操作に合わせ、画面が指に追従する横スワイプへ刷新
- ページ切り替え、フォルダ表示、ボタン操作、並べ替えを滑らかにアニメーション
- 設定からアニメーションの強さを0〜100%で調整可能
- フォルダをiPad風のアイコングリッドで表示し、アイコンからすぐアクセス
- ホーム上のフォルダにも登録先のファビコンを表示
- ウィジェットの削除・移動・サイズ変更ボタンを外側へ移し、タップ領域を拡大
- ページ移動ボタンを廃止し、アイテムを画面の左右端へドラッグして移動
- 最後のページの右端へドラッグすると、最大6ページの範囲で新規ページを自動作成
- 学校行事予定カウントダウンを削除

## そのほかの機能

- 全アイテムをグリッド単位で移動・拡大縮小
- 移動先プレビュー、衝突表示、配置の「元に戻す」
- 時間割を横一列、4＋3の二段、縦一覧、現在／次だけへサイズに応じて自動変更
- 50分授業、45分授業、自由設定の授業時刻
- 現在の授業、次の授業、開始・終了までの時間を表示
- Open-Meteoによる現在天気、降水確率、時間別・5日予報
- 地域名検索と、任意の現在地利用
- ショートカットを重ねてフォルダ作成
- フォルダ内のドラッグ並べ替え、取り出し、解除
- 最大6ページのホーム画面、横スワイプ・Shift＋ホイール
- 勉強向け、アイコン重視、シンプルの配置テンプレート
- 配置の名前付き保存、復元、削除
- 設定全体のJSON書き出し・読み込み
- Google、Bing、DuckDuckGo、YouTube、Googleマップ検索
- `yt`、`map`、`ddg`、`b`、`g` の検索コマンド
- 登録ショートカットの検索、URL直接入力、任意の端末内検索履歴
- 背景画像からテーマ色と明暗を自動生成
- ウィジェットごとの透明度、ぼかし、角丸、シャドウ、文字色、アクセント色
- 旧バージョンの配置・ショートカット・設定を自動移行

## 基本操作

- ページ切り替え：ホーム画面の空いている場所を左右にスワイプします。
- 配置編集：右上の「編集」を押し、アイテムまたは上部のつまみをドラッグします。
- ページ間移動：編集モード中にアイテムを左右端へ運び、そのまま離します。
- サイズ変更：編集モード中にアイテム右下の青いハンドルをドラッグします。
- フォルダ作成：編集モード中にショートカットを別のショートカットへ重ねます。
- フォルダを開く：通常モードでフォルダを押し、中のアイコンを押します。
- 設定を閉じる：×ボタンのほか、パネル外側を押しても閉じられます。

## Chromeへの読み込み方

1. ZIPを展開します。
2. Chromeで `chrome://extensions/` を開きます。
3. 「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. `manifest.json` が入っているフォルダを選択します。
6. 更新時は拡張機能一覧の更新ボタンを押し、新しいタブを開き直します。

## 授業時刻

初期値は次のとおりです。学校の時刻に合わせ、設定画面から「その他・自分で設定」を選ぶと各時限を編集できます。45分または50分の時刻を「その他」へコピーしてから微調整することもできます。

- 50分授業：8:40開始、昼休みを挟み、7限16:05終了
- 45分授業：8:40開始、昼休みを挟み、7限15:30終了

## 天気

天気はOpen-MeteoのForecast APIとGeocoding APIを利用します。APIキーは不要です。取得結果はブラウザ内に約30分キャッシュされ、通信できない場合は直近のデータを表示します。現在地は利用者がボタンを押した場合だけ取得します。

## データ保存

- 配置、ショートカット、フォルダ、授業時刻、テーマは `localStorage` に保存されます。
- 背景画像は `IndexedDB` に保存され、外部へ送信しません。
- JSONには背景画像そのものは含まれません。
- 検索履歴は初期状態では保存しません。設定で有効にした場合だけ端末内へ保存します。
