# NewTab

iPadOSをモチーフにした、検索・時計・時間割・天気のホーム画面です。GitHub Pagesと、Chromeの新しいタブを置き換える拡張機能の両方で利用できます。

**HTML / CSS / JavaScriptを分離しています。ビルド、npm、APIキーの設定は不要です。**

## GitHub Pagesで公開する

1. ZIPを展開します。
2. GitHubの公開先リポジトリで **Add file → Upload files** を開きます。
3. 展開したフォルダの**中身**をアップロードしてコミットします。`index.html` がリポジトリの一番上にある状態にしてください。ZIPファイルそのものを置くだけでは動きません。
4. **Settings → Pages** を開きます。
5. **Source: Deploy from a branch**、**Branch: main**、**フォルダ: / (root)** を選んで **Save** を押します。既存リポジトリで別のブランチを使う場合はその名前を選びます。
6. 公開が終わったら、Pages画面に表示される **Visit site** から開きます。

CSS、JavaScript、アイコン、オフライン用ファイルはすべて相対パスです。`https://ユーザー名.github.io/リポジトリ名/` のようなURLでも使えます。

公開方法の参考：[GitHub公式ガイド](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。公開ソースの指定は [Publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) を参照してください。

## Chromeの「新しいタブ」に設定する

GitHub Pagesに公開するだけでは、Chromeの新しいタブは自動で置き換わりません。この一式を拡張機能として読み込むと置き換わります。

1. ZIPを展開し、フォルダを残しておきます。
2. Chromeのアドレスバーに `chrome://extensions/` と入力します。
3. 「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を選びます。
5. `manifest.json` と `index.html` が入っているフォルダを選びます。
6. 新しいタブを開きます。

学校管理のChromebookで拡張機能の追加が制限されている場合は、公開したURLをブックマークして利用してください。拡張機能を更新するときは、ファイルを入れ替えて拡張機能一覧の更新ボタンを押します。

## 最初の設定

- **時間割**：右上の設定から、自分のクラスを選択します。初期値は101です。
- **天気**：初期値は金沢市です。設定で地域を検索し、候補から選べます。「現在地を使用」は自分で押したときだけ位置情報の許可を求めます。
- **壁紙**：設定の「画像を選ぶ」から指定します。画像の色に合わせて自動テーマを作成します。
- **イラスト検索**：初期状態では非表示です。設定の「ウィジェット」でオンにできます。

## 配置の操作

| 操作 | 方法 |
|---|---|
| 編集開始・保存 | 右上の「編集」／「完了」 |
| ウィジェットの移動 | 編集中、上のつまみをドラッグ |
| ショートカットの移動 | 編集中、アイコンをドラッグ |
| 大きさを変更 | 編集中、右下のハンドルをドラッグ |
| フォルダを作る | 編集中、アイコンを別のアイコンへ重ねる |
| フォルダへ追加 | アイコンをフォルダへ重ねる。ショートカットの編集画面からも選択可能 |
| フォルダ内の並べ替え | 編集中にフォルダを開き、アイコンをドラッグ。タッチにも対応 |
| フォルダから取り出す | 編集中にフォルダを開き、アイコンの×を押す |
| 別ページへ移す | 編集中、アイテムを画面の左右端へ運び、離す |
| ページ切り替え | 余白の横スワイプ、横スクロール、Shift＋ホイール、下のドット・矢印 |
| ページ追加・名前・順番・削除 | 設定の「ホーム画面のページ」。上限6ページ |
| 元に戻す | 編集中の「元に戻す」。Ctrl / Command＋Zにも対応 |

移動先が別のウィジェットと重なる場合は、赤い「配置できません」を表示し、その位置では確定しません。アイコン同士の重なりはフォルダ化の操作として扱います。

狭い画面では6列の配置を使います。横長画面での配置は別に保持するため、スマホ幅にしても元の配置を失いません。設定の列数は横長画面の6〜16列を指定します。

キーボードでは、移動用つまみやアイコンにフォーカスして矢印キーで1マス移動できます。サイズ変更ハンドルにフォーカスするか、Shift＋矢印キーでサイズを変更します。`/` で検索へ、Alt＋左右キーでページ切り替え、Escでモーダルを閉じます。

## ウィジェット

### 検索

Google、Bing、DuckDuckGo、YouTube、Googleマップから標準の検索先を選択します。

- `g 検索語`：Google
- `b 検索語`：Bing
- `ddg 検索語`：DuckDuckGo
- `yt 検索語`：YouTube
- `map 検索語`：Googleマップ
- URLを入力：そのページを直接開く
- 登録した名前を入力：ショートカットへ移動

検索履歴の保存は初期OFFです。ONにした場合だけ端末内へ保存します。Google候補は入力中の文字列をGoogleへ送信して取得します。GitHub PagesではGoogle側のCORS設定や学校の通信制限により候補を取得できない場合があります。その場合も検索、登録ショートカット、許可した履歴の候補は使えます。拡張機能には候補取得先の接続許可を指定しています。

### 時計

デジタル／アナログ、12時間／24時間を切り替えられます。時刻は端末の時計を使います。

### 時間割

`ns25350/NEWTAB2` と同じ次の読み取り先とデータ構造を使用します。

```text
https://johou7-275be-default-rtdb.firebaseio.com/timetable.json
schedules → 月曜・火曜… → クラス名 → 0〜6の授業名
```

`205/6文` はデータ上の `205_6文` に対応します。サーバーの時間割への書き込みは行いません。

今日／明日、現在／次の授業、開始・終了までの分数を表示します。設定時刻での翌日表示はオン／オフにできます。通信できない場合は保存済みの時間割を表示し、保存データであることを明記します。

- **50分**：8:40開始、昼休みを挟み、7限16:05終了
- **45分**：8:40開始、昼休みを挟み、7限15:30終了
- **自由設定**：各時限の開始・終了を編集。時刻の逆転や重なりは受け付けません

授業時刻は初期値です。実際の学校の時間に合わせて確認・変更してください。取得元は曜日別の時間割です。祝日や臨時休校などは、元データに反映されていなければ自動判定できません。

横長では7限を一列、中程度では4限＋3限、縦長では一覧、小さい場合は現在と次を優先します。内容が多い場合はウィジェット内でスクロールできます。

### 天気

Open-Meteoの現在天気、体感温度、最高・最低、降水確率、4時間分と5日分の予報を表示します。小さなサイズでは主要情報を優先します。取得結果は約30分間再利用し、接続に失敗したときは同じ座標の保存データだけを使用します。

[Open-Meteo](https://open-meteo.com/) / [API仕様](https://open-meteo.com/en/docs)。データはCC BY 4.0。無料APIを使う個人・非商用向けの構成です。利用条件は提供元の最新の案内を確認してください。

### イラスト検索

pixiv・X・Google画像の公式検索ページを開きます。pixiv日間ランキングへの導線もあります。Google画像はセーフ検索を指定し、Xは `filter:safe` を付けます。表示内容には各サービスのアカウント・年齢・表示設定が適用されます。

作品画像を取得・埋め込み・再配信する機能ではありません。最近の検索語は端末内に保存します。

## 外観とデータ

- ウィジェット背景の不透明度は0〜100%。文字や入力欄の内容へ親要素の `opacity` をかけません。
- ウィジェットごとに不透明度、ぼかし、角丸、影、文字色、アクセントを設定できます。
- 壁紙は20MBまで。長辺2560px以内に端末内で縮小し、IndexedDBへ保存します。外部へアップロードしません。
- 自動テーマのほか、Silver / Ocean / Rose / Darkを選べます。
- アニメーション強度を設定できます。0%またはOSの動きを減らす設定では動きを抑えます。
- 配置、ショートカット、フォルダ、テーマ、履歴はlocalStorageに保存します。端末・ブラウザ・公開元が違う場合は別データです。
- 配置には名前を付けて保存・復元・削除できます。名前付き保存はその時点のショートカット、フォルダ、ウィジェットの表示状態も保持します。
- JSON書き出し／読み込みに対応します。壁紙画像はJSONに入りません。読み込み時は現在の壁紙を引き継ぎます。
- ファビコンの取得では登録URLのホスト名だけをGoogleへ送ります。ページのパスやクエリは送りません。

既存v0.5の `homeGridStateV3`、旧V2／V1の設定は、同じ公開元で見つかった場合に読み込みます。別URL・拡張機能へ移行する場合はJSONを利用してください。

## オフライン・更新

GitHub Pagesでは初回オンライン表示後にアプリのHTML・CSS・JSを保存します。以降はオフラインでも保存した配置や時計を表示できます。外部検索・リンクの閲覧・最新情報の取得には通信が必要です。Chrome拡張機能ではアプリファイル自体が端末にあります。

Web版更新後に古い画面が残る場合は、このNewTabを開いているタブをいったん閉じ、開き直してください。コードを更新する場合は `sw.js` のキャッシュ名のバージョンも変更してください。
